# ytmaxxing logo: usage guide

**The mark:** a rounded play triangle with an upward chevron cut out of it. Watch it, level up.
**The wordmark:** "ytmaxxing" in a heavy sans, with the **xx** in the brand gradient.

## Files

| File | Use |
|---|---|
| `logo-primary.svg` | Mark + wordmark on light backgrounds |
| `logo-primary-dark.svg` | Mark + wordmark on its own dark tile |
| `logo-mark.svg` | Avatars, favicons, stickers |
| `logo-mark-black.svg` / `logo-mark-white.svg` | One-colour print, embossing, monochrome contexts |
| `favicon.svg` | Browser tab |
| `../../assets/banner.png` | README header (2560×840) |
| `../../assets/social-preview.png` | GitHub social preview (1280×640). Upload in repo **Settings → Social preview** |

## Colours

| Name | Hex | Use |
|---|---|---|
| Max Red | `#FF2A3D` | Gradient start, badges, accents |
| Ember | `#FF6A3D` | Gradient end |
| Deep Red | `#C4001D` | Text accents on white (passes 4.5:1) |
| Ink | `#0F0F10` | Dark backgrounds, wordmark on light |
| Paper | `#FFFFFF` | Light backgrounds, wordmark on dark |

The gradient runs top-left (Max Red) to bottom-right (Ember).

## Rules

- **Clear space:** keep empty space around the mark at least the height of its chevron.
- **Minimum size:** 16 px for the mark; 96 px wide for mark + wordmark.
- **Never** put the mark inside a red rounded rectangle, or pair it with YouTube's colours in a way that suggests YouTube made it. ytmaxxing is independent.
- **Never** stretch, rotate, outline, add drop shadows on light backgrounds, or recolour outside the palette.
- **Wordmark text** is set in the system sans-serif at weight 800. For print or merch, outline it first.
