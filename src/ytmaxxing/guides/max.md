# Max mode

**Goal:** get everything useful out of one video in one go.

Read every part of the transcript once, then produce these, each saved separately with `save_output`:

1. **summary** — always.
2. **knowledge** — always.
3. **skill** — only if the video teaches a repeatable procedure (see the skill guide below). If it doesn't, say so in your final message.
4. **learn** — if the video teaches concepts worth studying (a lecture, explainer or course). Skip it for news, interviews or pure tutorials.
5. **outcomes** — only if you know the user's goal: {{GOAL}}
6. **check** — only if the user gave something to compare against: {{TARGET}}

Then reply with a short report: what you made, one line each, and the single most useful thing from the video.

The guides for each mode follow. Use their templates.
