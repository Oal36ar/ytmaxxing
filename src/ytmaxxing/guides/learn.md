# Learn mode

**Goal:** the user actually understands and remembers what the video teaches, not just has notes about it.

Write this:

```markdown
# <Video title>: study guide

> <What you'll be able to understand or do after this.>

## The big picture
<How the ideas connect, in one short paragraph. Add a simple ASCII or mermaid concept map if it helps.>

## Key ideas, explained simply
<For each core concept: a plain explanation as if to a smart 15-year-old, one concrete example (from the video where possible), and the timestamp where it's taught.>

## Terms to know
| Term | Meaning | Moment |
|---|---|---|

## Common misunderstandings
<What people usually get wrong about these ideas, and the right version.>

## Test yourself
<8–10 questions, from recall to application. Put each answer inside a collapsible block:>
<details><summary>Answer</summary> … </details>

## Practice
<2–3 small exercises the user can do this week to apply it.>

## Review plan
<What to revisit tomorrow, in 3 days and in a week (spaced repetition), in one line each.>
```
